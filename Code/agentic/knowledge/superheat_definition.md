# 铝电解过热度基础知识（演示知识条目）

## 物理定义

电解质过热度通常定义为电解质实际温度减去电解质初晶温度：ΔT = T_bath - T_liquidus。初晶温度会随电解质成分变化。

## 输入边界

火眼图像模型输出的 C / N / H 是图像状态分类结果，可用于视觉状态或风险等级辅助判断。它不是温度测量，也不能单独给出以摄氏度表示的实际过热度。

没有实测电解质温度与可用的电解质成分/初晶温度依据时，不得报告数值过热度，不得仅凭图像生成加料、调压等工艺控制指令。
