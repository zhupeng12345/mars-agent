# 铝电解火眼多智能体诊断系统第9—25页图片生成提示词

> 用途：为第 9—25 页生成与前 1—8 页一致的课题汇报 PPT 示意图。
>
> 使用方式：每次生成一页时，同时上传前四张参考 PPT 图片作为“版式参考图”，再上传对应页需要使用的真实火眼图片、过程曲线、知识文档截图或系统截图作为“内容参考图”。每次只生成一张 16:9 单页，不生成多页拼图。

## 统一版式约束

请严格参考上传的前四张 PPT 图片的版式和信息层级，生成 16:9、1920×1080 的中文科研项目汇报单页。

- 白色或极浅灰色背景；
- 左上角红色粗体章节标题，字号大、位置固定；
- 标题下方使用深蓝色细横线，右侧接黄色短横线；
- 标题下方放浅蓝色圆角结论框，左侧放红色方块或菱形；
- 正文使用黑色、深蓝色和红色大字号文字；
- 主体使用紫色细边框、黑色虚线框、蓝色流程箭头和少量橙色强调；
- 使用真实火眼图片、真实铝电解现场照片、真实过程曲线、知识文档或系统截图；
- 采用“上方结论句—中部示意图—下方说明”的论文汇报结构；
- 每页只突出一个核心结论，正文保持 3—6 个信息块；
- 图片带细边框和轻微阴影，模块之间保持明显留白；
- 页面中文字必须短、准、可读，公式和英文名称保持原样。

禁止使用深蓝渐变背景、AI 工厂背景、3D 机器人、霓虹光效、玻璃卡片、复杂图标矩阵、营销海报、软件产品首页、透视建筑、发光粒子和过度装饰。不要自行增加标题、页脚、水印、宣传语或与项目无关的模型名称。

如果中文渲染不稳定，请优先保证布局、图片位置、边框、箭头和流程关系，文字区域保留清晰空白框，文字由 PowerPoint 后期手动输入。
