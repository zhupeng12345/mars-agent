# 示例图片 PPT 章节层级重组方案

## 一、问题判断

`示例图片.pptx` 当前有 29 个幻灯片对象，其中前 25 页各包含一张整页生成图片，后 4 页没有图片内容。内容页本身已经具备较完整的视觉风格和技术信息，当前主要问题是：

- 25 页标题处于同一层级，听众难以判断汇报主线；
- 数据、视觉算法、Agent 编排、RSI 和评测之间缺少章节边界；
- 连续的算法详解页容易被理解成并列功能清单；
- JEV、simple_loop、full_loop、RAG、案例记忆和人工确认属于同一条诊断主线，但目前没有被收束到一个“大章”中；
- PPT 末尾存在 4 张空白页，应在正式汇报前删除。

本次建议保留现有 25 张图片作为页面主体，只增加少量可编辑的 PPT 文字和导航元素。这样不会破坏已经生成的图片，也能让汇报从“25 个同层标题”变成“5 个章节、25 个小节”。

## 二、推荐的五章结构

| 大章 | 页码 | 章节名称 | 这一章回答的问题 |
|---|---:|---|---|
| 第一章 | 1—4 | 项目定位与问题定义 | 为什么做火眼多智能体诊断，系统要解决什么问题 |

```text

```

## 四、PPT 中的最小改动方案

### 1. 统一标题层级

现有生成图片作为底图保留，在每页上方增加一行小号章节眉题：

```text
第四章｜JEV 编排与多智能体诊断
```

原有页面标题前增加小节编号，例如：

```text
4.4 full_loop 多 Agent 并行协同
```

如果图片中的原标题无法覆盖，可以在原标题左侧增加一个窄小的白底编号框，只放 `4.4`，不要重做整页图片。

### 2. 增加章节导航带

在第 1、5、10、15、23 页，也就是每一章的第一张页面，标题下方增加一条窄导航带：

```text
项目定位　　数据与架构　　多模态感知　　JEV与Agent诊断　　演化与验证
```

当前章节使用红色或橙色高亮，其余章节使用深蓝色或灰色。导航带高度控制在 25—35 px，避免遮挡原图中的结论框。

### 3. 增加统一页码

右上角增加小号页码，使用“小节号 / 25”的形式：

```text
1.1 / 25
4.4 / 25
5.3 / 25
```

页码颜色使用深蓝或灰色，位置固定，便于听众定位。

### 4. 在封面内加入五章目录

不新增目录页，直接在第 1 页底部增加一条简洁目录带：

```text
01 项目定位　→　02 数据与架构　→　03 多模态感知　→　04 JEV与Agent诊断　→　05 演化与验证
```

目录带只显示五个大点，不放 25 个小节标题。这样可以保持总页数不变，也不会破坏封面主视觉。

### 5. 章节切换页不增加新页

第 5、10、15、23 页已经有内容，不需要插入新的章节过渡页。只需在这些页增加：

- 当前章节眉题；
- 当前章节名称；
- 五章导航带；
- 当前章节的核心句。

这样既能让听众感知章节切换，也不会让现有图片和页数发生较大变化。

## 五、推荐的标题样式

### 章节眉题

- 位置：左上角，主标题上方；
- 字号：16—20 pt；
- 颜色：深蓝或灰蓝；
- 格式：`第三章｜多模态感知与过程状态`；
- 字体：微软雅黑或思源黑体；
- 不使用全角长句，不添加宣传性描述。

### 小节编号

- 位置：原主标题左侧或标题第一行开头；
- 字号：与原主标题相同或略小；
- 颜色：红色；
- 格式：`3.3`、`4.4`、`5.2`；
- 与主标题之间留一个空格。

### 章节导航带

- 使用一条细蓝线和短黄色线，与参考 PPT 的标题下划线保持一致；
- 当前章节采用红色或橙色短线；
- 其他章节只保留深蓝色文字，不使用复杂图标。

## 六、汇报时的讲解层级

每次进入一个大章时，先用一句话说明本章要回答的问题，再讲页面内容。

### 第一章

“先说明现场问题和系统目标，明确火眼诊断为什么需要视觉、知识和 Agent 协同。”

### 第二章

“再说明系统使用哪些证据，以及这些证据如何被任务协议和状态机组织。”

### 第三章

“然后说明视觉和过程数据如何形成可解释的多模态证据。”

### 第四章

“接着说明 JEV 如何选择诊断循环，以及多个 Agent 如何在复杂任务中协同。”

### 第五章

“最后说明系统如何通过人工反馈、RSI 和评测形成可控的演化闭环。”

## 七、当前 PPT 的清理项

1. 删除或隐藏第 26—29 页空白幻灯片。当前 PPT 有 29 个幻灯片对象，但只有前 25 页包含内容图片。
2. 检查每页顶部标题是否被生成图片裁切，若无法覆盖原标题，只增加左上角小节编号和上方章节眉题。
3. 确保所有页面右上角页码格式一致。
4. 第 15 页开始进入 JEV 大章时，统一橙色 JEV、绿色 `simple_loop`、蓝色 `full_loop`、红色人工确认、紫色 RSI 的颜色语义。
