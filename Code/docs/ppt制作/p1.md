一、制作定位
本套 PPT 的主题不是“已有模型指标汇报”，而是展示一个面向铝电解火眼巡检的完整智能体系统设计。汇报要让听众在 25 页内理解四件事：

火眼视觉提供可解释的动态证据；
过程变量由独立 Process State Agent 形成工况先验；
JEV 根据任务难度选择简单诊断循环或多 Agent 完整循环；
知识、案例、人工确认和 RSI 共同形成可审计的闭环。

class FGMVAETemporal(nn.Module):
    def forward(self, roi_seq, expert_features, mask=None):
        spatial = self.encoder(roi_seq)
        temporal = self.temporal(spatial, mask=mask)
        prior = self.gmm_prior(self.fuzzy_head(expert_features))
        z = self.align_latent(temporal, prior)
        return self.head(z), self.uncertainty(z), temporal

def route_task(features, policy):
    if features.quality < policy.retake_quality:
        return JevRoute("retake", "quality")
    if features.risk == "high" or features.novelty > policy.ood:
        return JevRoute("human", "risk_or_ood")
    if features.confidence >= policy.fast_confidence \
       and features.case_score >= policy.case_score \
       and features.evidence_coverage >= policy.coverage:
