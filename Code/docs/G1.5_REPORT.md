# G1.5 阶段报告：多帧视觉与 F-GMVAE-T

- 状态：流程与结构通过，视觉精度待专家标签和 GPU。
- 实现：固定视频窗口、源视频分组切分、YOLO ROI 轨迹、关键帧/缺失掩码、Conv/GRU/TCN/Transformer、F-GMVAE-T 和可关闭损失项。

## 图像级监督基线补充

- `runtime_data/visual_training/fgmvae_t_image_supervised.pth` 为 10 轮 CPU 图像级监督 checkpoint；当前测试集 `n=927`，accuracy `0.7346`，Macro-F1 `0.7097`，ECE `0.2828`，Brier `0.3525`。
- 该结果来自 6158 张目录弱标签图片，且没有可审计的来源元数据，训练报告明确 `leakage_risk=high`、`unsafe_item_fallback=true` 和切分组重叠；视频窗口没有专家真值，因此只能作为图像级实验基线，不能写成视频或真实过热度指标。
- 最新视频演示确认使用 `input_mode=framewise_probability_pooling`、8 帧、模型 profile `fgmvae-t-image-supervised-v1`；该路径是对单帧监督 checkpoint 的受控降级，不等价于已训练的时序 F-GMVAE-T。
